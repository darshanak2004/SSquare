# S Square Elite — React + Vite storefront

## Run locally
1. Install Node.js 18+.
2. In this folder run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.
4. Run `npm run build` for a production build.

## Included
- React + Vite, responsive mobile-first storefront
- Full-bleed hero artwork with copy overlaid directly on the background (no separate hero image card)
- Category navigation, search, sorting, product cards, favourites, related products, cart drawer and quantity controls
- Frontend demo only: checkout is not connected to payments or a backend
- Product assets in `public/assets`
